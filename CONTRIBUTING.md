# Contributing

Thanks for helping. Issues and pull requests are welcome.

## Ground rules

- Code is MIT. Anything you add, including assets and dependencies, must be
  MIT-compatible. No GPL or LGPL code. Record every third-party item in
  [THIRD_PARTY.md](THIRD_PARTY.md) in the same pull request.
- Generation must stay deterministic. Take randomness only from `Pcg32`
  streams (`ctx.rng(stage, layer)`), never from `randi()`, `randf()`, the
  clock or dictionary order of unsorted data.
- If a change alters generated output on purpose, update the golden files
  (see below) and bump `SongGenerator.ENGINE_VERSION`.

## Godot conventions

- One scene per screen and per reusable control. Parents call down into
  children; children signal up.
- Data lives in Resources saved as `.tres`. New vibes, styles and SFX presets
  need no code: add a `.tres` to the matching folder in `resources/`.
- Keep autoloads to `AppState` and `AudioService`.
- Generation code is `RefCounted`, with static functions where possible, and
  never touches the scene tree.
- The plugin in `addons/chipforge/` must stay self-contained: it cannot
  depend on anything outside that folder.
- Use static typing everywhere.
- GDScript style follows the official style guide: tabs, `snake_case`,
  `##` doc comments on public classes and methods.

## Running the tests

```sh
godot --headless --path . --import
godot --headless --path . -s tests/run_tests.gd
```

Pass a name to run some of them: `-s tests/run_tests.gd -- test_sfx`.
When a change to generated output is intended, rewrite the golden files with
`-- --update-golden`, check the diff, and commit them.

## Checking layouts

The UI must work at phone, tablet and desktop widths. `tools/screenshot.gd`
captures any screen at any size and UI scale:

```sh
godot --path . -s tools/screenshot.gd -- 780 1688 2 phone.png
godot --path . -s tools/screenshot.gd -- 1440 900 1 sfx.png sfx SfxScreen
```

Below 600 logical pixels the app uses the phone layout, below 1100 the tablet
layout, and above that the desktop layout.

The README screenshots in `docs/screenshots/` come from this tool: desktop
shots at `1440 900 1` and phone shots at `780 1688 2`. Retake them when a
screen changes noticeably. The folder has a `.gdignore`, so Godot does not
import the images or ship them in exports.

## Building

Install the Godot 4.5.1 export templates, then:

```sh
godot --headless --path . --export-release "Web" build/web/index.html
godot --headless --path . --export-release "Linux" build/linux/chiptune-forge.x86_64
```

The web build uses the single-threaded template, so it runs on any static
host without special headers. CI builds Web, Linux, Windows, macOS and
Android on every push.

## Theme

`resources/theme/app_theme.tres` is generated by `tools/build_theme.gd`.
Change colours and sizes there and run
`godot --headless --path . -s tools/build_theme.gd`.
